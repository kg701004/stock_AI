# 自選個股追蹤

## 設定追蹤清單

複製 [sample_watchlist.csv](data/sample_watchlist.csv) 後修改。每位使用者可各自追蹤相同或不同股票：

```text
owner,symbol,name,current_price,reference_price,target_price,stop_price,as_of
```

- `reference_price`：開始觀察時的參考價，用來計算追蹤報酬率。
- `target_price`：到達後觸發「檢視續抱／分批獲利」提醒。
- `stop_price`：跌破後觸發「重新評估」提醒；它不是自動賣出指令。
- `current_price`：以最新公開盤後價格或手動更新的價格填入。

## 互動檢視

```powershell
python watchlist_app.py
```

點選自選個股後會顯示價格觸發條件、綜合分數與所有可用理由。這個功能只讀取本機 CSV，沒有券商連線、即時行情或下單能力。
