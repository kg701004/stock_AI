# 投資組合風險與曝險管理

此模組在「個股建議」之上，檢查整體持股是否過度集中或表面分散、實際高度相關。

## 已計算項目

- 每位持有人分開計算總市值與單一持股比重。
- 產業曝險與產業集中度。
- 加權 Beta。
- 若提供對齊的歷史報酬序列，計算持股間相關性並提示高相關組合。

可調整門檻位於 [portfolio_risk_rules.json](config/portfolio_risk_rules.json)：單股上限、產業上限、組合 Beta 上限與高相關性門檻。

執行範例：

```powershell
python portfolio_risk_report.py
```

Beta 與產業資料使用本機 [sample_security_metadata.csv](data/sample_security_metadata.csv) 的格式管理。缺少分類資料時，系統會明確警告，不會假設已分散。
