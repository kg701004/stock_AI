# 資料夾選擇與未來單一執行檔

## 第一次使用

未來應以 `stock_ai_app.py` 作為單一執行檔入口。首次啟動時，程式會開啟資料位置設定畫面：

```powershell
python stock_ai_app.py
```

你可選擇 D 槽、外接硬碟或任何有寫入權限的位置。按下「儲存並建立資料夾」後，系統會自動建立：

```text
選擇的位置\
├─ history.sqlite
├─ decision_audit.sqlite
├─ raw_archive\
├─ imports\
└─ backups\
```

## 設定保存位置

資料位置設定寫入使用者的 Windows AppData：`%APPDATA%\StockAI\storage.json`。因此未來 EXE 更新、移動或重新安裝時，不會遺失你的資料位置設定，也不會把資料寫在 EXE 同一資料夾。

之後可在主畫面點選「資料位置設定」更換位置；舊資料不會自動搬移，避免大量資料搬移時遺失。需要搬移時，先備份，再以複製方式搬到新位置，最後才切換設定。
