# 可調權重決策引擎

## 調整方式

編輯 [analysis_weights.json](config/analysis_weights.json) 的 `weights`。數字不必加總為 100，程式會自動正規化；例如把 `global_risk` 從 10 改為 20，代表它相對其他因素更重要。

| 因子 | 解釋 |
|---|---|
| technical | 趨勢、動能、突破、量價與技術指標 |
| market_breadth | 漲跌家數、新高新低、均線參與率 |
| sector_rotation | 產業相對強弱、成交占比、資金輪動 |
| fundamentals | 營收、獲利品質、現金流與成長 |
| institutional_flow | 三大法人、融資融券等盤後籌碼 |
| derivatives | 期貨基差、未平倉與 Put/Call 風險 |
| global_risk | 海外股市、利率、匯率、波動率等 |
| events | 財報、月營收、重大訊息等事件 |
| liquidity | 成交金額、價差與可交易性 |
| valuation | 本益比、股價淨值比、殖利率與相對估值 |

每一類因子分數都是 0–100，50 代表資料不足或中性，不能以缺資料直接當成偏多。`risk_score` 也為 0–100，但會依 `maximum_risk_penalty` 從總分扣除。

## 可調門檻

`thresholds` 可調整 `strong_watch`、`bullish_watch`、`neutral`、`high_risk`，以及最低流動性與最大風險扣分。程式會拒絕不完整、負權重、無效分數或分類門檻順序錯誤的設定。

## 可追溯性

每次結果會保存：原始因子分數、正規化權重、分數貢獻、說明、風險扣分、設定版本與設定檔 SHA-256 指紋。因此之後即使改過權重，也能知道舊判斷用的是哪一版設定。

## 執行

```powershell
python main.py
python -m unittest -v
```

產出的 `decision_audit.sqlite` 是本機稽核資料庫；它不含帳密或券商 API 資訊。
