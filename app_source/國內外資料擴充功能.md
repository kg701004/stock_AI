# 國內外股票資料擴充功能（非券商 API 版）

## 目的與邊界

本模組使用網路取得的公開盤後資料，不使用券商帳密、交易 API 或即時行情授權。它的定位是收盤後選股、隔日風險判斷與中期研究；不可宣稱具有逐筆即時性。

### 目前採用限制（使用者決定）

- 只使用免申請、免付費且公開可取得的資料。
- 不使用券商 API、即時 WebSocket、帳戶憑證或付費行情服務。
- 資料抓取必須符合來源的使用條款、速率限制與 robots 政策；來源改版或停止提供時，功能應顯示失敗，不得沿用過期資料冒充最新結果。

## 建議加入的功能

| 優先級 | 功能 | 主要輸出 | 可用公開資料 |
|---|---|---|---|
| P1 | 市場廣度 | 漲跌家數、創高／創低、站上 20/60MA 比例、上市櫃強弱 | TWSE、TPEx 日資料 |
| P1 | 市場狀態 | 多頭／震盪／空頭、高風險開關與策略門檻 | 市場廣度、指數、期權、海外風險 |
| P1 | 產業輪動 | 5/20/60 日相對強弱、成交金額占比、產業候選名單 | 個股日資料、產業分類、法人資料 |
| P1 | 基本面品質 | 營收成長、EPS、毛利率、ROE、現金流、估值 | MOPS/TWSE/TPEx 公開公告與財報 |
| P1 | 法人與融資 | 外資／投信／自營商趨勢、融資融券異常 | TWSE、TPEx 公開資料 |
| P2 | 台指期與選擇權 | 基差、OI 變化、Put/Call、波動風險 | TAIFEX 盤後資料 |
| P2 | 全球風險面板 | 美股指數、半導體指標、美元、利率、波動率與事件日曆 | 免申請的官方公開資料來源或手動 CSV 匯入 |
| P2 | 美國公司事件 | 10-K/10-Q/8-K、內部人申報、財報與供應鏈事件 | SEC EDGAR |
| P3 | 新聞事件 | 重大訊息去重、來源可信度、事件與產業映射 | 官方公告優先；新聞須遵守授權條款 |

## 已加入的離線分析元件

`market_context.py` 已加入可測試的市場環境引擎。它接收標準化的盤後快照，輸出：

- 市場狀態：`bullish`、`range_bound`、`bearish`
- 風險等級：`normal`、`moderate`、`high`
- 市場廣度比例、分數與逐條理由

此設計使資料擷取層與分析層分離：先可以用 CSV 或手動輸入驗證，之後接入任何合法公開來源時不須重寫判斷邏輯。

## 資料治理要求

1. 每筆資料保存資料日期、公布時間、抓取時間、來源 URL 與原始檔雜湊。
2. 盤後資料只能從下一個可交易時點起使用；禁止把盤後法人資料當成當日收盤前已知資訊。
3. 各來源設定快取、重試、速率限制與失敗告警；不要無限制爬取網站。
4. 海外資料需處理時區、休市日與台灣開盤前後的可用性。
5. 新聞、指數與付費數據必須確認授權；不以網頁爬蟲作為核心且無備援的資料來源。

## 正式接入順序

1. TWSE／TPEx：每日行情、法人、估值、當沖與市場廣度。
2. MOPS：月營收、財報公布與重大訊息。
3. TAIFEX：期貨、選擇權、Put/Call 與未平倉資料。
4. SEC EDGAR：美國公司申報、XBRL 基本面與 8-K 事件。
5. 合法且免申請的海外宏觀與指數來源，再建立台股产业／供應鏈影響映射；若無穩定公開來源，改採手動 CSV 匯入。

## 不應納入第一版的項目

- 付費、未授權的即時海外行情爬蟲。
- 需要開戶、申請 API、憑證或行情權限的券商服務。
- 將新聞情緒直接等同買賣訊號。
- 沒有歷史驗證就用海外指數直接預測台股個股。
- 以公開盤後資料冒充盤中即時訊號。
