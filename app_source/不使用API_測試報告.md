# 不使用 API 的可執行性測試

## 測試範圍

此測試刻意不使用網路、券商 SDK、公開資料下載或第三方套件。它以可重現的 Mock 行情驗證下列離線能力：資料模型、亂序 Tick 排序、1 分鐘 K 線聚合、SMA／RSI、可解釋掃描、SQLite 儲存與單元測試。測試資料庫寫在專案目錄，因為目前桌面沙箱禁止 Python 寫入系統暫存目錄。

## 可執行項目

| 功能 | 結果 | 說明 |
|---|---|---|
| Mock 行情 | 可行 | 固定 seed，可在非交易時間重現測試資料。 |
| K 線聚合 | 可行 | 可將 Tick 轉為 1 分鐘 K 線，並處理亂序輸入。 |
| 技術指標 | 可行 | SMA、RSI 等僅依歷史資料計算；資料不足時回傳空值。 |
| 掃描／評分 | 可行 | 可輸出均線、相對量、RSI 與風險理由。 |
| SQLite | 可行 | 可保存 K 線與訊號，供回放、統計與後續回測。 |
| 單元測試 | 可行 | 使用 Python 內建 `unittest`，不需 pytest。 |
| 日線盤後研究 | 可行但未納入本次離線測試 | 可使用手動匯入的 CSV，做指標、基本面與回測；公開資料的取得仍需網路。 |

## 不可行或必須降級的項目

| 項目 | 結論 | 原因與替代方案 |
|---|---|---|
| 真正即時報價 | 不可行 | 無資料串流來源。改用 Mock 或手動 CSV 匯入。 |
| 逐筆成交、五檔、委託簿 | 不可行 | 必須有券商／授權行情資料。 |
| 盤中爆量、急漲、即時突破警示 | 僅能模擬 | 可對 Mock／CSV 重播觸發，不能反映當下市場。 |
| 自動重連與訂閱恢復 | 不可測 | 沒有 WebSocket 連線。可先對抽象介面寫 Mock 測試。 |
| 盤中短線模型 | 資料不足 | 真實歷史 Tick／分鐘資料不可省略。 |
| 真實下單或模擬券商委託 | 不可行 | 需券商 API；本專案目前也明確禁止實盤下單。 |
| 官方公開資料自動更新 | 不可離線 | 即使不使用券商 API，抓取公開資料仍然需要網路。 |

## 執行方式

```powershell
python no_api_prototype.py
python -m unittest -v test_no_api_prototype.py
```

## 結論

不使用券商 API 仍可先完成約六成的工程基礎：資料結構、資料庫、K 線、技術指標、規則掃描、回放、回測框架與 UI 的 Mock 演示。不能取代的是盤中即時資料與微結構資訊；這些功能必須等真實行情來源接入後才可驗證。
