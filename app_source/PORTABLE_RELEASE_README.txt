股票 AI 可攜版使用說明

1. 請複製整個可攜版資料夾，不要只複製 StockAI.exe。
2. StockAI.exe 與 StockAI_Data 資料夾應保持在同一層。
3. 第一次啟動時，程式預設建議資料位置為：
   StockAI.exe 所在位置\StockAI_Data
4. 若舊設定指向不存在的磁碟（例如另一台電腦沒有 D 槽），程式會重新顯示資料位置設定，不會直接當機。
5. StockAI_Data 內包含 SQLite 資料庫、歷史原始檔、匯入資料與備份。
6. 若公司端點防護攔截未簽章 EXE，可改由系統管理員核准，或在已安裝 Python 的環境執行原始碼版本。

注意：
- 資料更新功能需要網路，且仍可能受公司 Proxy、TLS 憑證或端點防護政策限制。
- 本版本不會繞過公司資安機制。
