# 多人持股、損益與建議功能

## 可做的事

每一筆持股以 `owner + symbol` 分開處理，因此不同人即使持有相同股票，也可有不同成本、股數、未實現損益與建議。輸出包含：市值、成本、未實現損益金額、未實現損益率、建議動作、理由與觸發條件。

## 輸入持股

請複製並修改 [sample_positions.csv](data/sample_positions.csv)。欄位為：

```text
owner,symbol,shares,average_cost,current_price,as_of
```

`current_price` 在目前無即時行情的架構下，應填入你匯入的最新盤後收盤價；`as_of` 必須與因子分數資料的時間一致或可說明差異。

## 產生建議

```powershell
python portfolio_report.py
python portfolio_report.py data/sample_positions.csv data/sample_factor_scores.csv
```

程式依 [position_rules.json](config/position_rules.json) 輸出：

- **加碼觀察**：總分高於加碼門檻，且風險分數低於上限。
- **續抱觀察**：沒有觸發加碼或減碼條件。
- **減碼／風險控管**：總分低於減碼門檻，或風險分數高於減碼門檻。

這些是可調整的研究規則，不是下單指令。建議另行檢查持股集中度、稅費、流動性、個人投資期限與最大可承受虧損。

## 點選持股查看詳細判斷

```powershell
python portfolio_app.py
```

桌面面板會列出所有持有人與持股。點選任一列後，會顯示該筆持股的未實現損益、報酬率、續抱／加碼／減碼建議、所有觸發條件與理由。它只讀取本機 CSV，沒有券商連線與下單功能。
