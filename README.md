# stock_AI
股市分析自動化

## 安裝 Jules GitHub App 說明

為了讓 Jules AI 編碼助手能夠自動分析此專案、讀取/修改程式碼，請按照以下步驟完成安裝與設定：

### 步驟 1：登入 Jules
1. 進入 [Jules 官方網站](https://jules.google.com/)。
2. 點擊 **Login** / **Try Jules**，使用您的 Google 帳戶進行登入。
3. 如果是首次登入，請閱讀並同意隱私權聲明與服務條款。

### 步驟 2：連接 GitHub 帳戶
1. 在 Jules 主介面中，點擊 **Connect to GitHub account**（連接 GitHub 帳戶）。
2. 系統會重新導向至 GitHub 的授權頁面，請完成 GitHub 帳戶的授權流程。
3. 授權成功後，您會看到 GitHub App 的安裝與設定選項。

### 步驟 3：安裝 Jules GitHub App 到此專案
1. 選擇要安裝 Jules GitHub App 的 GitHub 帳戶或組織。
2. 在權限範圍設定中，您可以選擇：
   - **All repositories**（所有儲存庫）：允許 Jules 存取您帳戶下的所有專案。
   - **Only select repositories**（僅選取的儲存庫）：建議選擇此項，並在下拉選單中搜尋並勾選 `stock_AI` 專案。
3. 點擊 **Install & Authorize**（安裝並授權）按鈕完成安裝。

### 步驟 4：開始使用 Jules
1. 安裝完成後，系統會自動導回 Jules。如果沒有，請嘗試重新整理 Jules 頁面。
2. 在專案選擇器（Repo Selector）中選取 `stock_AI` 專案。
3. 選擇您要 Jules 工作的分支（例如 `main` 分支）。
4. 在輸入框中輸入您的需求或任務指令（例如：「撰寫測試程式」或「重構分析邏輯」），然後點擊 **Give me a plan**，即可開始享受 Jules 的 AI 自動化編碼服務！
